# 🛒 MERN E-Commerce Platform

A production-ready full-stack MERN E-Commerce application built from scratch using modern web development technologies and best practices.

---

## 🚀 Features

- User Authentication (JWT)
- User Roles (Admin & Customer)
- Product Catalog
- Categories
- Shopping Cart
- Wishlist
- Checkout
- Stripe Payments
- Order Management
- Product Reviews
- Admin Dashboard
- Responsive Design
- REST API
- Docker Support

---

## 🛠 Tech Stack

### Frontend

- React
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend

- Node.js
- Express.js

### Database

- MongoDB
- Mongoose

### Authentication

- JWT
- bcrypt

### Payments

- Stripe

### DevOps

- Docker
- GitHub Actions (Later)
